First App Class

You’re booked. Let’s get you set up.

About 10 minutes. Do this before class so we can build right away — not install software on the call.

  1. Step 1Required

    Install an editor

    Pick one. Cursor is recommended for this class.

    Download Cursor Download VS Code

    Recommended: Cursor. VS Code is fine too.

  2. Step 2Required

    Get a paid AI subscription

    You need Claude Pro+ or ChatGPT Plus+. Free tiers won’t cut it for class.

    Claude (Pro+) ChatGPT (Plus+)

    Pick one for now. Either works.

  3. Step 3VS Code only

    Install the AI extension

    Cursor users: skip this step — AI is built in. Sign in when Cursor asks.

    VS Code users: install one extension, then sign in.

    Claude Code for VS Code Codex for VS Code

    Before you install: check the publisher says Anthropic or OpenAI. Skip anything else.

  4. Step 4Required

    Install Expo Go on your phone

    This is how your app opens on your phone during class.

    Expo Go for iPhone Expo Go for Android
  5. Step 5Optional

    GitHub account

    Nice for saving projects later. Not needed to run the app in class with Expo Go.

    Create a free GitHub account
